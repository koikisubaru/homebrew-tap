# koikisubaru/homebrew-tap

Homebrew Cask tap for **MouseFlick** — free OS-wide mouse gesture grammar for macOS.

## Install

```bash
brew tap koikisubaru/tap
brew trust koikisubaru/tap   # required on Homebrew 7+
brew install mouseflick
```

Or in one line (after trusting the tap):

```bash
brew install koikisubaru/tap/mouseflick
```

Homepage & interactive browser simulator: https://mouseflick.com
